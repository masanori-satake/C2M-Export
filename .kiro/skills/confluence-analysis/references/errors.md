# エラー別リカバリ表

終了コード・状態ごとの「まず確認すること」と「次のアクション」です。分析が `error` や `partial` で終わった場合に参照してください。エラー発生時も標準出力には `status: "error"` の構造化 JSON が出力され、標準エラー出力に日本語の詳細メッセージが出力されます。

| 終了コード / 状態 | 意味 | まず確認すること | 次のアクション |
|---|---|---|---|
| `2` (`INVALID_PARAM`) | パラメータ不正 | 起点（`--space-key` / `--root-page-id` / `--all-spaces` / `--cql` のいずれか）の指定漏れ、値の形式。ジョブ操作の場合は job_id の形式 | 直して再実行する。同じ内容での自動リトライはしない |
| `3` (`AUTH_FAILED`) | 認証失敗 | 環境変数 `C2M_CONFLUENCE_TOKEN`（または `CONFLUENCE_TOKEN`）が設定されているか | 利用者にトークンの設定と有効性の確認を依頼する。再試行を繰り返さない |
| `4` (`TARGET_NOT_FOUND`) | 対象未存在（未知の job_id もこのコード） | Space キー / ページ ID の綴りと参照権限。ジョブ操作の場合は job_id の取り違え | 利用者に確認する |
| `5` (`API_ERROR`) | Confluence API / ネットワークエラー | 一時的な障害かどうか（ジョブの場合は `--job-status` の `stale` 等の周辺情報も） | 時間をおいて1回だけ再試行を提案する |
| `6` (`partial`) | 部分成功 | `uncertainties.interrupted_reason`（中断理由）と `collected_page_count`（収集済み件数） | どこまで終わったかを利用者へ伝え、`--resume` での再開を提案する |
| `10` (`INTERNAL_ERROR`) | 内部エラー | 標準エラー出力の日本語詳細メッセージ | 再試行せず、詳細とともに利用者へ報告する |
| ジョブの `stale: true` | ワーカー異常終了の疑い | ジョブの `log_file`（worker.log） | ログの要点を利用者へ報告し、再開するかどうか判断を仰ぐ |
