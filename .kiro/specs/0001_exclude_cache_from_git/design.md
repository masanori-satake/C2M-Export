# 設計: キャッシュディレクトリの git 管理対象外化

## 方針

`.gitignore` ファイルにキャッシュ関連のエントリを追加する最小限の変更。

## 変更対象

- `.gitignore` のみ

## 追加するエントリ

既存の `# Pytest` セクションの直後に、関連するキャッシュ・カバレッジ用のセクションを追加する。

```
# Mypy
.mypy_cache/

# Ruff
.ruff_cache/

# Coverage
.coverage
htmlcov/
```

## 既存エントリとの整合性

| パターン | 現状 | 対応 |
|---|---|---|
| `__pycache__/` | 記載済み（# Python セクション） | 変更不要 |
| `.pytest_cache/` | 記載済み（# Pytest セクション） | 変更不要 |
| `.mypy_cache/` | 未記載 | 追加 |
| `.ruff_cache/` | 未記載 | 追加 |
| `.coverage` | 未記載 | 追加 |
| `htmlcov/` | 未記載 | 追加 |

## リスク分析

- 追加するパターンはすべてツール生成物であり、ソースコードやテストファイルとは名前が衝突しない
- ワイルドカードではなくディレクトリ名・ファイル名を明示指定するため、意図しない除外は発生しない
