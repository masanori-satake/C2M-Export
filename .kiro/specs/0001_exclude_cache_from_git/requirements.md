# 要件: キャッシュディレクトリの git 管理対象外化

## 背景

`.mypy_cache` など実行時・開発時に自動生成されるキャッシュディレクトリがローカルに存在し、`.gitignore` に記載がないためうっかりコミットされるリスクがある。これらを git 管理対象に含めると、リポジトリの肥大化や環境差異による不正動作の原因となる。

## 要件

1. 以下のキャッシュ関連パスを `.gitignore` に追加し、今後 git 追跡対象にならないようにする
   - `.mypy_cache/` — mypy 型チェックキャッシュ
   - `.ruff_cache/` — ruff リンターキャッシュ
   - `.coverage` — pytest-cov カバレッジデータ
   - `htmlcov/` — カバレッジ HTML レポート

2. 既に `.gitignore` に記載済みの以下は変更不要（確認のみ）
   - `__pycache__/`
   - `.pytest_cache/`

3. 現時点で git 追跡済み（コミット済み）のキャッシュファイルが存在する場合は `git rm --cached` で追跡を解除する
   - 確認の結果、現時点ではコミット済みのキャッシュファイルは存在しない

4. プロジェクトに必要なファイル（ソースコード、テスト、設定サンプル等）が誤って除外されないこと

## 受け入れ基準

- `.gitignore` に上記 4 パターンが記載されている
- `git status` でキャッシュディレクトリが untracked として表示されない（ignored として扱われる）
- プロジェクトの必要なファイルが引き続き追跡されている
