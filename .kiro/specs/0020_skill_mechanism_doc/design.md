# Design: スキルの仕組み解説ドキュメント（spec 0020）

## 構成

`docs/skill_mechanism.md` の章立て:

1. 全体像（構成図）
2. スキルの配置と同期（複製の図）
3. SKILL.md の構造設計（progressive disclosure、トークン予算）
4. 状況判断ロジック（見積もり → 決定表、フローチャート）
5. 同期処理の流れ（シーケンス図）
6. 非同期処理の流れ（シーケンス図、ジョブ状態遷移図）
7. チェックポイントと再開（フロー図）
8. JSON データの管理（クラス図、ファイルライフサイクル図、取り違い・削除忘れ対策の一覧）
9. 品質を保つ仕組み（監査・計測・レビュー）

## 方針

- 図は Mermaid の flowchart / sequenceDiagram / stateDiagram-v2 / classDiagram を使い、保守者が GitHub 上でそのまま読める形にする。
- 数値（閾値 120 秒 / 500 ページ / 300 秒、ハートビート 5 秒、stale 90 秒）は実装の定数と対応づけて書く。
- コードの詳細な内部実装（収集アルゴリズム等）には踏み込まず、スキルと CLI の接点に絞る。
