# Requirements: スキルの仕組み解説ドキュメント（spec 0020）

## 背景

spec 0011〜0019 で、スキルと分析 CLI の間に多くの仕組み（見積もり、決定表、非同期ジョブ、チェックポイント、references 分離など）が入った。これらはコードとスキル文書だけでは意図が追いにくく、将来の保守者が全体像を掴むための解説が要る。

## 要件

- `docs/skill_mechanism.md` を新規作成する。使い方ガイドである `docs/ai_integration.md` とは役割を分け、こちらは「仕組みと設計意図」の解説とし、冒頭で相互参照する。
- UML 図を Mermaid 形式でできるだけ多く入れる（構成図、シーケンス図、フローチャート、状態遷移図、クラス図）。
- 同期処理・非同期処理それぞれの処理の流れと、どちらを選ぶかの状況判断ロジック（見積もりと比較する決定表、閾値の根拠）を詳しく書く。
- スキルと CLI の間でやり取りされる JSON データについて、取り違いや削除忘れが起きないようにする管理の仕組み（識別子、ファイル配置、原子書き込み、スコープハッシュ、成功時の削除、要約返却など）を説明する。
- 記述は実装と照合して正確に書く。README.md のドキュメント一覧にも追加する。

## 完了条件

- ドキュメントが作成され、図が Mermaid として妥当な構文で書かれている。
- 取り上げた数値・条件が実装（閾値、間隔、終了コード、ファイル名）と一致している。
