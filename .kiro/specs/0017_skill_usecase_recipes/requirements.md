# Requirements: ユースケース別レシピ集（spec 0017）

## 背景

SKILL.md 本体の「分析ユースケース一覧」は各 usecase の1行説明のみで、「何のために、どのパラメータで実行し、結果のどこを見るか」はエージェントの裁量に残っている。スキル UX 改善の第3弾として、目的別のレシピを用意する。

## 要件

- 1.1 レシピは references/usecases.md に置く（本体の残り予算が約 630 トークンしかなく、毎回の実行で全レシピは不要なため）。本体のユースケース一覧の末尾にポインタを1行追加する。
- 1.2 各レシピは「目的 / 推奨パラメータ・コマンド例 / 結果の見どころ」の形に統一する。見どころは実装の実在フィールド名（counts の各キー等）で書く。
- 1.3 対象は6 usecase とワークスペース全体把握（`--all-spaces`）の計7本。
- 1.4 どのレシピでも先に `--estimate` で規模を確認し、本体の決定表に従う前提を明記する。
- 1.5 コードの変更はしない。references は3箇所へ同期する。
