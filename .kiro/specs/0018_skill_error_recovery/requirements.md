# Requirements: エラー別リカバリ表（spec 0018）

## 背景

SKILL.md 本体には終了コードの一覧はあるが、エラー時に「まず何を確認し、次にどうするか」は書かれていない。認証失敗で再試行を繰り返す、パラメータ不正で同じ実行を繰り返すといった無駄なターンを防ぐため、スキル UX 改善の第4弾としてリカバリ表を用意する。

## 要件

- 1.1 リカバリ表は references/errors.md に置く（エラーが起きた実行でだけ必要で、本体の予算も残り約 630 トークンのため）。本体の「終了コード規約」の末尾にポインタを1行追加する。
- 1.2 終了コード 2 / 3 / 4 / 5 / 6 / 10 と、ジョブの `stale` を対象に、「意味 / まず確認すること / 次のアクション」を表にする。
- 1.3 再試行の扱いを区別する: パラメータ不正と認証失敗は繰り返さない、API エラーは時間をおいて1回だけ、内部エラーは再試行しない。
- 1.4 コードの変更はしない。references は3箇所へ同期する。
